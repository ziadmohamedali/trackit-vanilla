# TrackIt 📋

A simple web app to manage your daily tasks easily.

🔗 **Live Demo:** [Try TrackIt Here](https://ziadmohamedali.github.io/trackit-vanilla/)

## Features
* **Add & Delete:** Quickly create or remove tasks.
* **Filter:** View all, completed, or waiting tasks.
* **Responsive:** Works great on mobile phones and computers.

## Built With
* HTML5
* CSS3
* JavaScript

## How to Run Locally
1. Download the code.
2. Open `index.html` in your web browser.
